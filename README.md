# CampusFix

## Funcionalidades implementadas

- Criação e consulta de pedidos de suporte.
- Tratamento e conclusão de pedidos por técnicos.
- Comentários associados aos pedidos.
- Gestão de categorias.
- Pesquisa de pedidos.
- Dashboard com três indicadores: pedidos abertos, em tratamento e concluídos.

## Perfis de acesso

- **Utilizador:** cria pedidos, consulta os seus pedidos e adiciona comentários.
- **Técnico:** consulta pedidos, assume pedidos, altera o estado, adiciona comentários e conclui o tratamento.
- **Administrador:** gere categorias e consulta a informação da aplicação.

## Funcionalidades opcionais

- Filtros e pesquisa nas listas de pedidos.
- Dashboard com indicadores por perfil.
- Registo automático do criador, datas e estado dos pedidos.
- Interface adaptada para facilitar a utilização dos formulários.
